========================================
PROJECT OVERVIEW
========================================

This project is a simple, clean, and responsive digital art gallery.
All artworks are generated by Artificial Intelligence (DALL-E 3 / Midjourney).
The gallery allows users to explore artworks in a calm and professional way.

========================================
FEATURES
========================================

✓ 16 AI-generated artworks
✓ 4 different moods (Happy, Sad, Calm, Mysterious)
✓ 5 interactive pages:
   - Home page
   - Gallery page (all artworks)
   - Search page (text search + mood filter)
   - Details page (for each artwork)
   - About page

✓ Search system works on:
   - Artwork title
   - Artist name
   - Description
   - Mood (you can type "sad" or "happy")

✓ Mood filter buttons (Happy, Sad, Calm, Mysterious)
✓ Responsive design (works on mobile, tablet, and desktop)
✓ Clean code with comments

========================================
HOW TO RUN THE PROJECT
========================================

Method 1 (Recommended):
- Open the folder in VS Code
- Right-click on index.html
- Select "Open with Live Server"

Method 2:
- Double-click on index.html directly
- The project will open in your browser

Method 3 (Online):
- Visit: https://SoftwereEngenOMBettol.github.io/art-gallery/

========================================
TECHNOLOGIES USED
========================================

- HTML5 (structure)
- CSS3 (design, Flexbox, Grid, Media Queries)
- JavaScript ES6 (interactivity, search, filter)
- JSON (data storage)
- All images generated by AI (DALL-E 3 / Midjourney)
