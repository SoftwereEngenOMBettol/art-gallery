## 📖 Project Overview

This project is a **simple, clean, and responsive** digital art gallery.  
All artworks are **generated by Artificial Intelligence** (DALL-E 3 / Midjourney).  
The gallery allows users to explore artworks in a **calm and professional** way.

---

## ✨ Features

| Feature | Description |
| :--- | :--- |
| 🖼️ **16 AI Artworks** | All images are unique and AI-generated |
| 🎭 **4 Moods** | Happy 😊, Sad 😢, Calm 😌, Mysterious 🔮 |
| 📄 **5 Pages** | Home, Gallery, Search, Details, About |
| 🔍 **Smart Search** | Searches in title, artist, description, and mood |
| 🎚️ **Mood Filter** | One-click filter by mood |
| 📱 **Responsive** | Works on mobile, tablet, and desktop |
| 🧹 **Clean Code** | Well-commented and organized |
